# The Pelican Order
### A Self-Replicating Spiral Lattice for getting paid 
## In Memory Of

**Barbara McLeish**

My grandmother. She carried the Stewart line from Perthshire, Scotland — through Caputh and Clunie, across the sea to Australia. The pelican on the Stewart crest feeds her young with her own blood. This lattice is named after her family's bird.

*Virescit vulnere virtus.*

---

## What This Is

The Pelican Order is a portfolio framework. It recruits nodes (stocks, livestock, anything trackable) into a 4-quadrant lattice, assigns each a weekly growth target based on statistical confidence tiers, and releases a node only when it has doubled AND cleared its exit threshold.

Same math governs a stock portfolio and a herd of cattle.
